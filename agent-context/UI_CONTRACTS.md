# UI Contracts & Visual Design System

1. **Color Palette**: Agricultural Green (`crop-700`: `#2B6248`), Dark Heading Green (`crop-950`: `#0F261D`), Light Off-White Background (`#FBFBF8`), Earthy Accent Badges.
2. **Typography**: Clean sans-serif with bold numbers for key indicators (`87/100`, `₹83,000`, `2 Acres`).
3. **Card Layouts**: Subtle borders (`border-slate-200`), rounded corners (`rounded-xl`), controlled shadows (`shadow-subtle`).
4. **Icons**: Lucide React icons throughout interface.
5. **Responsive Breakdown**:
   - Mobile: Single column, large tap targets, stacked card comparisons.
   - Desktop: Multi-column grid dashboards, sticky summary panels, dynamic charts.
